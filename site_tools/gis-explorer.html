How to Investigate a Different Site
Each layer = one .geojson file. To study your own site:
  1. Click dl on a sample layer to download it
  2. Open it in any text editor — it is plain JSON
  3. Change the coordinates to your site (use geojson.io to draw polygons and copy the output)
  4. Save as .geojson and drag it back here
Or export from QGIS / ArcGIS: any GeoJSON in WGS84 (EPSG:4326) works.
// minimal site GeoJSON — copy and edit { "type": "FeatureCollection", "features": [{ "type": "Feature", "properties": { "name": "My Site A", "use": "vacant lot" }, "geometry": { "type": "Polygon", "coordinates": [[[lng,lat], ...]] } }] }
