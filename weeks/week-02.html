Architecture Uses Many Evidence Types

  • precedent
  • standards and code
  • site observation
  • stakeholder input
  • simulation
  • measurement
  • published research
  • benchmarks and case comparisons
  • your own option studies and tests (variant A vs B against the same criteria)

Not All Inputs Are Equal

Useful question:
Did this input actually reduce uncertainty for the decision?

If not, it may have been:

  • inspiration
  • convention
  • assumption
  • noise

A Fast Evidence Ladder

Usually stronger:

  • measured performance
  • well-matched comparative evidence
  • relevant standards and verified constraints
  • a documented comparison of your own design variants, if the criteria were stated before the result

Usually weaker:

  • isolated precedent images
  • vague “best practice”
  • unsupported confidence from the designer

The last rung of each list is the same material — the designer’s own judgment. What moves it up the ladder: criteria stated first, identical comparison conditions, documented before the outcome.

A1 Core Move

Do not prove that your earlier design was right.

Do this instead:

  • name the decision clearly
  • separate evidence from assumption
  • admit what was missing
  • define what you would need next time

Fast Audit Template

Input used then Type Strength What it really supported
precedent image visual precedent low-medium form and atmosphere, not performance
simulation screenshot model output medium comparison only if assumptions were sound
code requirement standard high within its scope compliance, not overall quality
option study (two massing variants) self-generated comparison medium if criteria were stated beforehand which alternative the scheme could tolerate

Common Overclaims

  • “there was evidence” when there was only precedent
  • “the model proved it” when the assumptions were weak
  • “users prefer this” from a tiny or biased sample
  • “this is best practice” without context

Stand-Alone Prompt

If you were defending one design claim about this project, what evidence would you want before making that claim in public?

Pivot to the Next Decision

The second half of A1 asks:

  • what is the next real design decision?
  • who needs to be convinced?
  • what evidence would matter?
  • which pathway might help most?

Pathway Sniff Test

Choose provisionally:

  • spreadsheet if you mainly need comparison, ranking, or visible logic
  • GIS if space, site, access, zoning, or context is central
  • Python if the question needs repeatable analysis or notebook-based workflow

Studio Exercise

In pairs:

  1. Explain your prior decision in one minute
  2. Let your partner identify the weak evidence link
  3. Rewrite your “next decision” as one question the semester could realistically address

A1 Reality Check

If your A1 is still vague, it is usually because:

  • the original decision was too broad
  • the evidence types are mixed together
  • the next decision is still a theme instead of a choice
  • the audience for the evidence is still unclear

A1 Submission Check

  • one prior decision, clearly described
  • one evidence audit
  • one next studio decision
  • one visual page that makes the transition visible
