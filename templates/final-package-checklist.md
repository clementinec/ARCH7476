# Final Package Checklist

Use this before A4 submission.

## Package Components

| Component | Included? | Notes |
|---|---|---|
| Practice Case, 2 slides | yes / no |  |
| Research Brief, 2 pages | yes / no |  |
| Object Card, 1 page | yes / no |  |
| Reproducibility Capsule | yes / no |  |
| Reflection Note | yes / no |  |

## Decision Loop Check

The final package clearly shows:

- [ ] design decision
- [ ] variants or scenarios
- [ ] workflow route
- [ ] evidence output
- [ ] threshold or comparison rule
- [ ] design action
- [ ] uncertainty or limit

## Practice Case Check

- [ ] decision is visible within 10 seconds
- [ ] recommendation is clear
- [ ] threshold or comparison rule is stated
- [ ] visual evidence supports the action
- [ ] caveat is not hidden

## Research Brief Check

- [ ] method is understandable
- [ ] input sources are named
- [ ] assumptions are stated
- [ ] uncertainty is addressed
- [ ] output is interpreted without overclaiming

## Object Card Check

- [ ] one dominant figure
- [ ] direct title
- [ ] legible labels and units
- [ ] no decorative data
- [ ] next action visible

## Reproducibility Capsule Check

- [ ] README
- [ ] data/source list
- [ ] workflow artifact
- [ ] figure sources
- [ ] prompt/code notes if relevant
- [ ] verification or failure log
