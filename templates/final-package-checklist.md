## Decision Loop Check

The final package clearly shows:

- [ ] design decision
- [ ] variants or scenarios
- [ ] workflow route
- [ ] evidence output
- [ ] threshold or comparison rule
- [ ] design action
- [ ] uncertainty or limit

## Practice Case Check

- [ ] decision is visible within 10 seconds
- [ ] recommendation is clear
- [ ] threshold or comparison rule is stated
- [ ] visual evidence supports the action
- [ ] caveat is not hidden

## Research Brief Check

- [ ] method is understandable
- [ ] input sources are named
- [ ] assumptions are stated
- [ ] uncertainty is addressed
- [ ] output is interpreted without overclaiming

## Object Card Check

- [ ] one dominant figure
- [ ] direct title
- [ ] legible labels and units
- [ ] no decorative data
- [ ] next action visible

## Reproducibility Capsule Check

- [ ] README with step-by-step run instructions
- [ ] environment / dependency list (tools and versions)
- [ ] data/source list
- [ ] the runnable workflow artifact (script / workbook / project / notebook — not only a screenshot)
- [ ] figure sources
- [ ] **re-running the workflow reproduces the key figure**
- [ ] prompt/code notes if relevant
- [ ] verification or failure log

## Feedback + Revision Ledger Check

- [ ] at least three feedback entries
- [ ] each entry names what assumption, metric, threshold, figure, route, or claim was challenged
- [ ] each entry states what changed
- [ ] rejected or deferred feedback is explained, not hidden
- [ ] final package reflects the accepted revisions
