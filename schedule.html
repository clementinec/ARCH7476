Course Schedule

12-Week Tool-to-Evidence Roadmap

Weekly Schedule Overview

The semester now has a clear sequence:

  1. survey the tool landscape
  2. choose one primary pathway
  3. prototype a method
  4. turn evidence into a studio-facing decision brief

At a Glance

Week Focus In-class emphasis Assignment alignment
1 Why Evidence Needs a Workflow course reset, evidence examples, A1 kickoff A1 launch
2 Audit the Evidence You Already Use prior decisions, evidence types, next studio question A1 due
3 Spreadsheet as Baseline Workflow tables, charts, comparison logic, transparent reasoning pathway survey
4 GIS Choices for Architects QGIS vs ArcGIS vs geopandas, Jupyter setup pathway survey
5 BIM, BEM, and Building Performance model types, translation loss, simulation as evidence pathway commitment
6 Evidence and Pathway Mapping source quality, scoping, tool choice, work plan A2 due
7 Method Prototype Studio minimal viable workflow, data inputs, outputs, QC A3 draft
8 Pilot, Compare, and Quantify Uncertainty pilot review, uncertainty, peer critique A3 due
9 Thresholds and Decisions decision criteria, trade-offs, counter-arguments A4 analysis
10 Visualize and Document the Workflow figures, process capture, reproducibility A4 draft
11 Studio Evidence Package Workshop review, refinement, audience fit A4 near-final
12 Object Fair and Transfer Forward presentation, critique, next-studio handoff A4 due

Week 1: Why Evidence Needs a Workflow

Focus

Reset the course around decisions, evidence, and tool choice instead of disconnected software demos.

In Class

  • course overview and new pathway model
  • architecture examples that appear evidence-based but hide weak reasoning
  • introduction to A1: prior decision audit plus next decision brief
  • mixed-cohort expectations for undergraduates, MArch, and PhD students

Out of Class

  • identify one prior design decision you already made
  • gather the images, notes, and sources you used at the time
  • identify one upcoming studio decision worth investigating

Tools Introduced

  • overview only: spreadsheet, GIS, Python, BIM/BEM

Week 2: Audit the Evidence You Already Use

Focus

Make existing habits explicit: what counted as evidence, what was missing, and what confidence was overstated.

In Class

  • evidence types: precedent, measurement, simulation, standards, observation, stakeholder input
  • how architects confuse confidence with evidence
  • workshop: convert a prior decision into an evidence audit
  • workshop: define the next studio question

Out of Class

  • submit A1
  • shortlist two possible pathways for your next question
  • gather 3-5 precedent or data sources for Week 3

Tools Introduced

  • spreadsheet as universal audit tool

Week 3: Spreadsheet as Baseline Workflow

Focus

Use spreadsheets as the common baseline for organizing evidence and comparing alternatives.

In Class

  • structure a worksheet around a design decision
  • move from raw observations to comparable fields
  • make charts that show uncertainty instead of false precision
  • build a simple decision matrix

Out of Class

  • create a starter workbook for your own project
  • prepare one comparison table and one chart

Tools Introduced

  • Excel / Google Sheets

Week 4: GIS Choices for Architects

Focus

Compare QGIS, ArcGIS, and geopandas, then situate code-based GIS inside a practical notebook workflow.

In Class

  • when to use QGIS
  • when ArcGIS matters in professional ecosystems
  • why geopandas is the course anchor for code-based GIS
  • Jupyter Notebook, Anaconda / Miniconda, and Colab: what each one does
  • minimal geopandas demo: load, inspect CRS, filter, buffer, plot, export

Out of Class

  • decide whether GIS is still in contention for your primary pathway
  • run the sample notebook or attend setup support

Tools Introduced

  • QGIS
  • ArcGIS
  • Jupyter Notebook
  • geopandas

Week 5: BIM, BEM, and Building Performance

Focus

Teach BIM/BEM and simulation as shared literacy, especially what gets lost when models travel between workflows.

In Class

  • BIM vs BEM: different data structures and different priorities
  • why translation breaks
  • what performance tools can and cannot tell you
  • how simulation fits inside evidence-based design without pretending certainty
  • pathway selection check-in

Out of Class

  • lock your primary pathway
  • collect candidate evidence sources and method ideas for A2

Tools Introduced

  • BIM/BEM concepts
  • building performance simulation examples

Week 6: Evidence and Pathway Mapping

Focus

Translate the studio question into a realistic evidence plan and commit to one primary pathway.

In Class

  • evidence source quality and relevance
  • compare pathway fit: spreadsheet, GIS, Python
  • define inputs, outputs, constraints, and likely failure points
  • A2 work session and feedback

Out of Class

  • submit A2
  • start a minimal folder/workbook/notebook structure for A3

Week 7: Method Prototype Studio

Focus

Build the smallest workflow that can answer a real piece of the question.

In Class

  • minimal viable method design
  • pathway breakout support
  • documenting assumptions before running the workflow
  • quality checks and version discipline

Out of Class

  • run the first full prototype
  • capture screenshots, exports, and notes

Week 8: Pilot, Compare, and Quantify Uncertainty

Focus

Use pilot work to refine the method and express confidence honestly.

In Class

  • what counts as a useful pilot
  • uncertainty ranges, scenario comparison, and data quality checks
  • peer critique focused on method fit and overclaiming
  • A3 refinement clinic

Out of Class

  • submit A3
  • decide what evidence will appear in the final package

Week 9: Thresholds and Decisions

Focus

Move from “interesting findings” to a decision rule someone can actually use.

In Class

  • set thresholds and ranges
  • compare alternatives without hiding trade-offs
  • define stakeholder-facing recommendations
  • address counter-arguments and weak spots

Out of Class

  • draft A4 recommendation logic
  • refine charts, maps, or notebook outputs

Week 10: Visualize and Document the Workflow

Focus

Make the method and the evidence legible to others.

In Class

  • figure design for architectural audiences
  • workflow diagrams and reproducibility notes
  • what to show from a spreadsheet, GIS map, or notebook
  • draft evidence board / object card review

Out of Class

  • assemble A4 draft package
  • prepare review materials for Week 11

Week 11: Studio Evidence Package Workshop

Focus

Pressure-test the near-final decision brief against its audience.

In Class

  • peer review of argument, evidence, and visual clarity
  • pathway-specific troubleshooting
  • tighten the link between evidence and next-studio action
  • polish final package structure

Out of Class

  • finalize A4
  • prepare final presentation materials

Week 12: Object Fair and Transfer Forward

Focus

Present the work as something that can move into the next project, not just end the semester.

In Class

  • final presentations and critique
  • object fair / evidence board display
  • reflection: what changed in how you justify design moves
  • transfer plan for the next studio project

Out of Class

  • submit A4
  • archive your pathway files and documentation for future reuse
