# Adversarial Review Response

An adversarial review was run from two perspectives:

1. skeptical MArch student
2. seasoned architecture educator

The core critique was accepted:

> The rebuild is pointed in the right direction, but it must not become another course that talks about workflows rather than having students build one.

## Accepted Changes

| Review concern | Response |
|---|---|
| Generative design was underdefined | Added working definition: generative = creates or varies multiple design options and evaluates them against explicit criteria |
| A3 could be too weak | Revised A3 to require variants/scenarios, evaluation, threshold, and design action |
| A4 could become generic evidence work | Revised A4 to require an evidence-backed generative workflow and variants/scenarios |
| Supported tool set was too broad | Added starter-kit status and support levels |
| DCP components should be required | Practice Case, Research Brief, Object Card, and Reproducibility Capsule are required in A4 |
| Missing assets are launch-blocking | Added launch gate and starter-kit readiness table |

## Remaining Blockers

The rebuild is not student-ready until these are built:

1. GH parametric starter kit with actual `.gh` or `.ghx` file.
2. Preset simulation or proxy-test kit with runnable example.
3. AI-assisted workflow kit with prompt log, failed output, repair, and verification example.

## Current Position

The course structure is now more defensible, but the practical promise depends on committing real tool artifacts.

This is the next major build step.
