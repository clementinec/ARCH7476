Starter kits are the practical base for the rebuilt course.

The launch course is built around routes that can be demonstrated with the files here. Some advanced bridges remain optional extensions.

## Minimum Kit Standard

Each kit should include:

- README
- input file or source description
- student task
- expected output
- verification check
- example final figure or table
- known failure modes

## Course Promise Check

If a route is listed as fully supported, a student should be able to start from the kit and adapt it to their own studio project without the instructor inventing the route during class.

Bridge routes are allowed when a student already has the setup, but they should not be required for A4.
