# AI-Assisted Workflow

**Launch status:** not ready. Spec only.

## Purpose

Show students how AI can help build a workflow component without becoming unverified evidence.

## Required Demo Example

Before launch, build one of:

- AI-generated GH Python component
- AI-assisted Python notebook function
- AI-generated workflow documentation
- failed AI output repaired through manual verification

## Minimum Demo Loop

1. task prompt
2. generated output
3. failure or risk
4. manual verification
5. corrected workflow component
6. disclosure statement

## Student Adaptation Task

Students use AI for one bounded workflow task or explain why AI is not appropriate.

## Verification Checks

- code or component runs
- units and scale are correct
- output is compared against a manual or known result
- AI role is disclosed
- design judgment remains with the student
