Course Resources

Setup Ladder, Pathway Guide, and Data Sources

Setup Ladder

The course supports different levels of technical comfort. Use the lightest setup that still lets you complete your chosen pathway well.

Baseline for Everyone

  • Spreadsheet software: Excel (HKU license) or Google Sheets
  • Web browser: Chrome, Firefox, or Safari
  • Course downloads: notebooks, sample data, and local image assets

GIS / Python Local Setup

1. Python Environment

Use Anaconda or Miniconda if you want a managed local environment.

  • Anaconda: bigger install, more batteries included
  • Miniconda: lighter install, better if you only want what the course uses

2. Notebook Interface

Use Jupyter Notebook as the main interactive environment.

  • run provided examples
  • edit cells and notes in one place
  • keep code, charts, and interpretation together

3. Browser Fallback

Use Google Colab if local installation is not ready yet.

  • good for quick starts
  • lower setup burden
  • less control over local files and environments
What These Names Mean
  • Anaconda / Miniconda = Python environment and package manager
  • Jupyter Notebook = the interface where you run and annotate code
  • pandas / geopandas = the libraries used inside notebooks
  • Colab = browser-based fallback if you do not want a local install yet

Suggested Install Order

  1. Confirm spreadsheet access
  2. Install QGIS if you want the GIS route
  3. Install Anaconda or Miniconda if you want GIS code or Python
  4. Open Jupyter Notebook
  5. Run one sample notebook before modifying anything

Pathway Chooser

Pathway Best when your question is about Common outputs Typical student fit
Spreadsheet comparisons, ranking, observations, literature/evidence tables charts, matrices, summary tables anyone; best baseline
GIS site, zoning, access, urban context, spatial trade-offs maps, buffers, overlays, spatial comparisons students with site or urban questions
Python repeatable analysis, plotting, lightweight modeling, reusable scripts notebooks, charts, cleaned datasets, export tables students who want more control or reuse

GIS Alternatives for Architects

The course explicitly introduces three GIS paradigms:

QGIS

  • free and open-source
  • good for visual exploration, layering, and manual map production
  • useful when you need fast spatial inspection without writing code

ArcGIS

  • important professional ecosystem
  • useful for enterprise, client, and institutional contexts
  • relevant if your collaborators or office already use it

geopandas

  • the course anchor for code-based GIS
  • useful when you need reproducible spatial analysis in notebooks
  • sits naturally beside pandas, plotting libraries, and exported CSV data

Why geopandas Sits at the Center

The course does not treat code-driven GIS as an abstract option. It teaches a small, concrete geopandas workflow in Jupyter Notebook so students understand:

  • how spatial data looks in code
  • how projections and geometry affect analysis
  • how to move from raw layers to a decision-support plot or export

Building Performance Literacy

All students get shared literacy in:

  • BIM vs BEM: different data structures, different priorities
  • simulation workflows: useful, but never automatically authoritative
  • translation loss: what breaks between design models and performance models
  • uncertainty: why numerical output still needs judgment

These support the whole course even if they are not the student’s chosen primary pathway.

Notebook Resources

Existing Course Notebooks

  • notebooks/01_python_ml_basics.ipynb
  • notebooks/02_arch_viz_analysis.ipynb

Recommended use:

  • use the second notebook first if you are new to Python
  • use the first notebook if you want a broader introduction to modeling concepts
  • adapt them rather than starting from a blank notebook

Example Bank

Included examples currently support:

  • workplace and systems claims
  • public-space observation

Attribution and source links are recorded in assets/examples/sources.csv.

  • site-specific images, counts, notes, and precedent material collected by students

Global / Open

Support

During the Semester

  • office hours for setup and pathway troubleshooting
  • in-class work sessions for assignment development
  • peer review for method fit and clarity

When to Ask for Help

Ask early if:

  • you cannot run the provided notebook example
  • your GIS data will not open or align correctly
  • your spreadsheet structure is collapsing under too many ad hoc columns
  • your chosen method does not yet produce a decision-relevant output

Quick Start

  1. Choose spreadsheet
  2. Build a clean comparison table for A1 and A2
  3. Add GIS or Python only if the question truly needs it

  1. Install QGIS
  2. Run the geopandas starter notebook in Jupyter or Colab

If You Want Python

  1. Install Anaconda or Miniconda
  2. Open the provided notebook in Jupyter
  3. Reproduce one chart using your own small dataset before scaling up

# Setup Ladder

The course supports different levels of technical comfort. Use the lightest setup that still lets you complete your chosen pathway well.

## Baseline for Everyone

- **Spreadsheet software**: Excel (HKU license) or Google Sheets
- **Web browser**: Chrome, Firefox, or Safari

## GIS / Python Local Setup

### 1. Python Environment

Use **Anaconda** or **Miniconda** if you want a managed local environment.

- `Anaconda`: bigger install, more batteries included
- `Miniconda`: lighter install, better if you only want what the course uses

### 2. Notebook Interface

Use **Jupyter Notebook** as the main interactive environment.

- run provided examples
- edit cells and notes in one place

### 3. Browser Fallback

Use **Google Colab** if local installation is not ready yet.
